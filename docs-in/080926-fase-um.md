## Fluxo de Requisicao

```
1. Cliente faz requisicao HTTP
        │
        ▼
2. Service (ClusterIP) encaminha para o Pod
        │
        ▼
3. FastAPI recebe a requisicao
        │
        ▼
4. Middleware coleta metricas (Prometheus)
        │
        ▼
5. Router direciona para o endpoint apropriado
        │
        ▼
6. InferenceService.processa (mock)
        │
        ▼
7. Retorna resposta JSON
```

## Solucao de Problemas Comuns

### Erro: kind: comando nao encontrado

```bash
# Instala Kind
curl -Lo ./kind https://kind.sigs.k8s.io/dl/v0.20.0/kind-linux-amd64
chmod +x ./kind
sudo mv ./kind /usr/local/bin/kind
```

### Erro: Pod em CrashLoopBackOff

```bash
# 1. Ver logs
kubectl logs -n jc-kubescale -l app=jc-kubescale-api

# 2. Verificar se a imagem existe
docker images | grep jc-kubescale-api

# 3. Reconstruir e recarregar
make build
make load-image
kubectl rollout restart deployment jc-kubescale-api -n jc-kubescale
```

### Erro: Port-forward nao funciona

```bash
# 1. Verifica se o pod esta rodando
kubectl get pods -n jc-kubescale

# 2. Reinicia port-forward
pkill -f "kubectl port-forward.*8080"
kubectl port-forward -n jc-kubescale svc/jc-kubescale-api 8080:8080

# 3. Tenta porta alternativa
kubectl port-forward -n jc-kubescale svc/jc-kubescale-api 8081:8080
curl http://localhost:8081/health
```

### Erro: ModuleNotFoundError: No module named 'app'

```bash
# Verifica estrutura de __init__.py
cd services/api/src
find . -name "*.py" | sort

# Deve conter:
# ./app/__init__.py
# ./app/api/__init__.py
# ./app/core/__init__.py
# ./app/models/__init__.py
# ./app/services/__init__.py
# ./__init__.py
```

# JC-KubeScale AI - O que e isso?

## Em Palavras Simples

Imagine que voce quer usar um assistente de IA (como o ChatGPT) no seu programa de computador.

Normalmente, para fazer isso voce precisaria:

1. Baixar um modelo de IA gigante (que ocupa muitos gigabytes)
2. Ter um computador super potente com placa de video cara
3. Configurar um servidor para rodar o modelo
4. Gerenciar quando o servidor deve ligar ou desligar
5. Monitorar se o servidor esta funcionando bem

O JC-KubeScale AI faz tudo isso automaticamente para voce!

## O Problema que Resolvemos

Modelos de IA (LLMs) sao diferentes de programas normais:

- **Consomem muita memoria** - Um modelo pode ocupar 10GB ou mais
- **Precisam de GPU** - Placas de video especiais para processamento
- **Demoram para iniciar** - Carregar um modelo pode levar varios minutos
- **Custam caro** - Servidores com GPU sao mais caros

## Como Funciona para o Usuario

Voce so precisa fazer uma requisicao simples:

```bash
curl http://localhost:8080/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "O que e Kubernetes?"}'
```

E a plataforma cuida de todo o resto!

## O que a Plataforma Faz por Voce

### 1. Gerencia o Modelo

- Baixa e carrega o modelo de IA
- Decide qual modelo usar
- Mantem o modelo pronto para uso

### 2. Gerencia os Servidores

- Cria servidores quando necessario
- Desliga servidores quando nao estao em uso
- Distribui as requisicoes entre os servidores
- Recupera automaticamente se algo falhar

### 3. Monitora Tudo

- Verifica se esta tudo funcionando
- Registra quantas requisicoes estao chegando
- Mede o tempo de resposta
- Guarda historico para analise

### 4. Escala Automaticamente

- Se muitas pessoas usarem ao mesmo tempo, cria mais servidores
- Se poucas pessoas usarem, desliga servidores extras
- Isso economiza dinheiro!

## Como Voce Pode Usar

## Perguntas Frequentes

### Preciso ter uma GPU para testar?

Nao! Para testes locais, usamos um "mock" (simulacao) que responde como se fosse a IA real.

### Quanto custa?

O software e gratuito (open source). Voce so paga se rodar na nuvem (AWS, GCP, Azure).

### Preciso ser especialista em Kubernetes?

Nao! O projeto foi feito para que voce nao precise saber nada de Kubernetes para usar.

### Posso usar meu proprio modelo de IA?

Sim! A plataforma e extensivel e permite adicionar novos modelos facilmente.
